# Tic-Tac-Toe but with matchmaking

## Описание игры

Это улучшенная версия классической игры "Крестики-нолики", где два игрока соревнуются в **серии из 9 матчей** друг против друга. Основная цель — **набрать больше очков, чем соперник**, за счёт победы в матчах и стратегического захвата клеток на глобальной карте.

### Основные особенности:
1. **9 матчей против одного соперника**:
   - Игра состоит из 9 отдельных матчей, в которых два игрока соревнуются друг против друга.
   - За победу в одном матче игрок получает **1 балл**.

2. **Глобальная карта**:
   - После каждого матча побеждённая клетка на глобальной карте 3x3 отмечается символом победителя (X или O).
   - Если игрок собирает **выигрышную комбинацию** (три клетки в ряд, столбец или диагональ) на глобальной карте, он получает **дополнительный балл**.

3. **Итог игры**:
   - Игра завершается после 9 матчей.
   - Победителем становится игрок, набравший **больше очков** (максимум 10 баллов: 9 за победы в матчах и 1 за глобальную комбинацию).

---

## Как играть

### Правила классического матча:
1. Игроки по очереди ставят **X** или **O** на поле 3x3.
2. Побеждает тот, кто первым соберёт три своих символа в ряд (по горизонтали, вертикали или диагонали).
3. Если все клетки заполнены, но никто не выиграл, матч заканчивается ничьей.

### Глобальная механика:
1. После каждого матча побеждённая клетка на глобальной карте 3x3 отмечается символом победителя.
2. Если игрок собирает три клетки в ряд на глобальной карте, он получает **дополнительный балл**.
3. Игра продолжается до тех пор, пока не будут сыграны все 9 матчей.

---

## Пример игрового процесса

1. **Матч 1**:
   - Игрок X выигрывает матч и захватывает клетку (1, 1) на глобальной карте.
   - Счёт: X — 1 балл, O — 0 баллов.

2. **Матч 2**:
   - Игрок O выигрывает матч и захватывает клетку (2, 2).
   - Счёт: X — 1 балл, O — 1 балл.

3. **Матч 3**:
   - Игрок X выигрывает матч и захватывает клетку (3, 3).
   - Счёт: X — 2 балла, O — 1 балл.

4. **Глобальная карта**:
   - Если игрок X захватывает клетки (1, 1), (2, 2) и (3, 3), он получает дополнительный балл за диагональ.
   - Счёт: X — 3 балла, O — 1 балл.

5. **Итог**:
   - После 9 матчей игроки сравнивают свои очки. Побеждает тот, у кого больше баллов.

## Как запустить игру

1. Убедитесь, что у вас установлен Rust и Cargo.
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/everyofflineuser/tictactoe.git
   ```
3. Перейдите в директорию проекта:
   ```bash
   cd tictactoe
   ```
4. Запустите игру:
   ```bash
   cargo run
   ```
